# 🎵 Gandharva-Omni AI Music Studio

Gandharva-Omni is a fine-tuned multilingual music studio intelligence model powered by `Qwen2.5-7B` + LoRA.

### 5 Specialized Studio Modes:
1. **Lyrics Studio**: Multilingual structured songwriting with chord charts (Telugu, Hindi, Tamil, English, etc.).
2. **Magic Prompt Enhancer**: Converts basic musical ideas into production engineering prompts with BPM, Key, and acoustic textures for MusicGen & ACE-Step.
3. **Story-to-Album Blueprint**: Analyzes narrative text and generates structured JSON multi-track album blueprints.
4. **Music Director & Arrangement**: Recommends tempo, root key, time signatures, and instrument stems.
5. **Vocal Coach**: Provides pitch, dynamic envelopes, and performance tips.
